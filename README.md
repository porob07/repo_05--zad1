android:gravity     ->    działa na dowolny element, ustawia położenie zawartości elementu [na przykład, położenie tekstu w polu TextView]
android:layout_gravity -> oddziałowywuje jedynie na dzieci kontenerów, ustawia położenie elementu wewnątrz kontenera [na przykład, Button w layout'cie]
